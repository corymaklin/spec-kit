
## 🚀 `/suggest-approaches` Command

The `/suggest-approaches` command helps you quickly generate potential **implementation approaches** for a given issue — whether it’s a bug, new feature, refactor, or enhancement.
It analyzes the issue description and provides structured, actionable suggestions.

---

### 🧩 Usage

Type the following in Claude Code (e.g., inside VS Code, Cursor, or any editor that supports Claude commands):

```bash
/suggest-approaches "Add CSV export to dashboards"
```

## 🚀 `/generate-test-cases` Command

The `/generate-test-cases` command helps you generate potential **test scenarios** for a given issue — whether it’s a bug, new feature, refactor, or enhancement.
It analyzes the issue description and provides structured test cases that developers can use to validate the implementation.

---

### 🧩 Usage

Type the following in Claude Code (e.g., inside VS Code, Cursor, or any editor that supports Claude commands):

```bash
/generate-test-cases "Add CSV export to dashboards"
```
